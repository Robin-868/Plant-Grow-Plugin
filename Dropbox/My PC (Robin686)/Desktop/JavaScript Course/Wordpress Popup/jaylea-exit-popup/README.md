# Jaylea Exit Popup Plugin

A powerful WordPress plugin that captures visitors before they leave with a customizable exit-intent popup and top bar notification system.

## 🌟 Features

### Exit Intent Popup
- **Smart Exit Detection**: Detects when users are about to leave using mouse movement and scroll behavior
- **Mobile Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Customizable Design**: Full control over colors, text, images, and styling
- **Device Targeting**: Choose which devices should display the popup
- **Session Management**: Shows only once per session to avoid annoying visitors

### Top Bar Notification
- **Persistent Notification**: Display a notification bar at the top or bottom of pages
- **Customizable Messaging**: Add your own message with emoji support
- **Optional CTA Button**: Include a call-to-action button with custom URL
- **Position Control**: Choose top or bottom placement
- **Dismissible**: Users can close the notification if enabled
- **Device Targeting**: Control visibility on different device types

### Analytics Dashboard
- **Real-time Tracking**: Monitor popup and top bar performance
- **Conversion Metrics**: Track displays, clicks, and conversion rates
- **Separate Analytics**: Individual performance data for each feature
- **Combined Overview**: Total performance metrics across both features
- **Google Analytics Integration**: Automatic event tracking support

## 🚀 Installation

1. Download the plugin files
2. Upload to `/wp-content/plugins/jaylea-exit-popup/`
3. Activate the plugin through the 'Plugins' screen in WordPress
4. Go to **Settings → Jaylea Popup** to configure your settings

## ⚙️ Configuration

### Exit Intent Popup Settings
- **Status**: Enable/disable the exit popup
- **Content**: Customize title, message, and features list
- **Image**: Upload an optional image
- **Button**: Set button text and destination URL
- **Appearance**: Choose background and text colors
- **Targeting**: Select which devices should show the popup

### Top Bar Notification Settings
- **Status**: Enable/disable the top bar
- **Message**: Customize the notification message
- **Button**: Optional call-to-action button
- **Position**: Top or bottom of page
- **Closeable**: Allow users to dismiss the notification
- **Appearance**: Custom colors and styling
- **Targeting**: Device-specific visibility

## 📊 Analytics

The plugin provides comprehensive analytics including:

- **Total Displays**: Combined popup and top bar views
- **Total Clicks**: Combined button clicks
- **Overall Conversion Rate**: Combined performance metrics
- **Individual Performance**: Separate stats for popup vs top bar
- **Time Tracking**: Analytics start date and daily averages
