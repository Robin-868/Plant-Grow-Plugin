Capture visitors before they leave with a beautiful, customizable exit intent popup.

== Description ==

Exit Intent Popup helps you capture visitors who are about to leave your blog posts. Show them a compelling message, image, and call-to-action to increase newsletter signups, engagement, and conversions.

**Features:**
* Exit intent detection (mouse movement + scroll behavior)
* Fully customizable popup design
* Image upload support
* Mobile responsive
* Easy-to-use admin interface
* Live preview in admin
* Analytics tracking ready
* Only shows once per session

**Perfect for:**
* Newsletter signups
* Lead magnets
* Special offers
* Social media follows
* Content recommendations

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/exit-intent-popup/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Settings → Exit Popup to configure your popup
4. Customize your message, colors, and call-to-action
5. Enable the popup and save settings

== Frequently Asked Questions ==

= Does this work on mobile devices? =
Yes! The plugin includes mobile-specific detection methods and responsive design.

= How often does the popup show? =
The popup shows only once per browser session to avoid annoying visitors.

= Can I customize the appearance? =
Absolutely! You can change colors, add images, customize text, and modify the call-to-action button.

= Will this slow down my site? =
No, the plugin is lightweight and only loads on blog posts where it's needed.

## Installation Instructions

1. **Create the folder structure:**
   ```
   exit-intent-popup/
   ├── exit-intent-popup.php
   ├── readme.txt
   └── assets/
       ├── admin.js
       ├── popup.css
       └── popup.js
   ```

2. **Copy each file** from above into the correct location

3. **Create a ZIP file** of the entire `exit-intent-popup` folder

4. **Upload to WordPress:**
   - Go to your WordPress admin
   - Navigate to Plugins → Add New
   - Click "Upload Plugin"
   - Choose your ZIP file
   - Click "Install Now"
   - Activate the plugin

5. **Configure:**
   - Go to Settings → Exit Popup
   - Customize your popup settings
   - Save and test!

The plugin is now production-ready with professional styling, mobile responsiveness, and a clean admin interface. It includes analytics tracking hooks and follows WordPress coding standards.
